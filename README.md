# Hospitalization Risk Stratification in Mexican Respiratory Surveillance Data

This repository contains the reproducible analytical notebook supporting the article:

**Hospitalization Risk Stratification in Mexican Respiratory Surveillance Data: A Retrospective Analysis with Interpretable Machine Learning**

## Overview

This project analyzes open Mexican respiratory surveillance data to identify factors associated with hospitalization and evaluate hospitalization risk stratification using interpretable machine learning.

The workflow includes:

- Data-quality review and preprocessing
- Handling of special coded values
- Exploratory data analysis
- Statistical association testing
- Logistic regression for interpretability
- Threshold tuning to improve recall
- Random Forest as a comparative predictive model
- Model performance evaluation

## Repository contents

- `hospitalization_risk_stratification_mexico_respiratory_surveillance.ipynb`  
  Main reproducible analytical notebook.

## Purpose

This repository is provided as supplementary reproducibility material. The study should not be interpreted as a standalone machine learning exercise, but as an applied public health analytics workflow designed to transform open respiratory surveillance data into interpretable hospitalization risk indicators for future monitoring and preparedness.
